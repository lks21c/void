# 확장 시스템

> **문서 목적**: Void의 플러그인/확장 아키텍처 분석 - hdsp-agent 확장 가능한 시스템 설계 참고

---

## 1. 개요

Void는 VSCode의 확장 시스템을 그대로 활용합니다. 94개의 내장 확장과 함께 사용자 정의 확장을 지원하며, 격리된 실행 환경과 RPC 기반 통신을 제공합니다.

### 1.1 핵심 파일

| 파일 | 역할 |
|------|------|
| `platform/extensions/common/extensions.ts` | 확장 정의 |
| `platform/extensionManagement/common/extensionManagement.ts` | 확장 수명주기 |
| `workbench/api/common/extensionHostMain.ts` | 확장 호스트 부트스트랩 |

```typescript
interface IExtension {
  id: string;                    // publisher.name
  name: string;
  displayName?: string;
  publisher: string;
  version: string;
  engines?: {
    vscode: string;
  };
  activationEvents?: string[];
  main?: string;                 // 진입점 경로
  browser?: string;              // 웹 확장 진입점
  contributes?: IContributions;
}

interface IContributions {
  commands?: ICommand[];
  menus?: { [contextId: string]: IMenu[] };
  configuration?: IConfiguration;
  views?: { [containerId: string]: IView[] };
  languages?: ILanguage[];
  grammars?: IGrammar[];
  themes?: ITheme[];
  snippets?: ISnippet[];
  debuggers?: IDebugger[];
}

interface ICommand {
  command: string;
  title: string;
  category?: string;
  icon?: string | { light: string; dark: string };
  enablement?: string;           // when 조건
}

interface IMenu {
  command: string;
  alt?: string;                  // Alt+클릭 시 대체 명령
  when?: string;                 // 표시 조건
  group?: string;                // 메뉴 그룹
}
```

## 3. 활성화 이벤트

### 3.1 이벤트 유형

| 이벤트 | 설명 | 예시 |
|--------|------|------|
| `onCommand:*` | 명령 실행 시 | `onCommand:myExt.run` |
| `onLanguage:*` | 언어 파일 열릴 때 | `onLanguage:typescript` |
| `onView:*` | 뷰 표시 시 | `onView:myView` |
| `onUri` | URI 스킴 접근 시 | `onUri` |
| `onFileSystem:*` | 파일 시스템 접근 시 | `onFileSystem:ftp` |
| `onWebviewPanel:*` | 웹뷰 패널 생성 시 | `onWebviewPanel:myPanel` |
| `onStartupFinished` | 시작 완료 후 | - |
| `*` | 항상 (즉시 활성화) | - |

### 3.2 활성화 로직

```typescript
class ExtensionActivationManager {
  private activatedExtensions = new Set<string>();

  async activateByEvent(event: string): Promise<void> {
    const extensions = this.getExtensionsForEvent(event);

    for (const extension of extensions) {
      if (!this.activatedExtensions.has(extension.id)) {
        await this.activateExtension(extension);
      }
    }
  }

  private getExtensionsForEvent(event: string): IExtension[] {
    return this.allExtensions.filter(ext =>
      ext.activationEvents?.some(ae =>
        this.matchesEvent(ae, event)
      )
    );
  }

  private matchesEvent(pattern: string, event: string): boolean {
    if (pattern === '*') return true;

    // onCommand:myExt.* -> onCommand:myExt.foo
    if (pattern.endsWith('*')) {
      return event.startsWith(pattern.slice(0, -1));
    }

    return pattern === event;
  }

  private async activateExtension(extension: IExtension): Promise<void> {
    const module = await this.loadExtensionModule(extension);
    await module.activate(this.createContext(extension));
    this.activatedExtensions.add(extension.id);
  }
}
```

### 4.2 확장 호스트 메인

```typescript
class ExtensionHostMain {
  private readonly _extensionService: IExtensionService;
  private readonly _rpcService: IExtHostRpcService;

  async start(): Promise<void> {
    // 1. 서비스 초기화
    await this.initializeServices();

    // 2. RPC 채널 설정
    this.setupRpcChannels();

    // 3. 확장 스캔 및 로드
    const extensions = await this.scanExtensions();

    // 4. 확장 활성화 준비
    for (const extension of extensions) {
      this.prepareExtension(extension);
    }

    // 5. 초기 활성화 이벤트 처리
    await this.processInitialActivations();
  }

  private setupRpcChannels(): void {
    // 메인 프로세스와의 RPC 채널
    this._rpcService.set(
      ExtHostContext.MainThreadCommands,
      this.createCommandsProxy()
    );
  }
}
```

### 4.3 확장 에러 핸들링

```typescript
class ExtensionErrorHandler {
  static async installEarlyHandler(accessor: ServicesAccessor): Promise<void> {
    const logService = accessor.get(ILogService);
    const rpcService = accessor.get(IExtHostRpcService);

    // 전역 에러 핸들러 설치
    setUnexpectedErrorHandler(err => {
      logService.error(err);

      // 메인 프로세스에 에러 전달
      const data = transformErrorForSerialization(err);
      rpcService.getProxy(MainContext.MainThreadErrors)
        .$onUnexpectedError(data);
    });
  }

  static async installFullHandler(accessor: ServicesAccessor): Promise<void> {
    const extensionService = accessor.get(IExtensionService);

    // 스택 트레이스에서 확장 식별
    const extensionIndex = await extensionService.getExtensionPathIndex();

    // Error.prepareStackTrace 래핑
    Object.defineProperty(Error, 'prepareStackTrace', {
      set(value) {
        originalPrepareStackTrace = (error, frames) => {
          // 확장 컨텍스트 추가
          const extensionId = findExtensionFromFrames(frames, extensionIndex);
          if (extensionId) {
            error._extensionId = extensionId;
          }
          return value(error, frames);
        };
      }
    });
  }
}
```

### 5.2 RPC 서비스

```typescript
interface IExtHostRpcService {
  getProxy<T>(identifier: ProxyIdentifier<T>): T;
  set<T>(identifier: ProxyIdentifier<T>, value: T): void;
}

class ExtHostRpcService implements IExtHostRpcService {
  private readonly _proxies = new Map<string, any>();

  getProxy<T>(identifier: ProxyIdentifier<T>): T {
    if (!this._proxies.has(identifier.id)) {
      this._proxies.set(identifier.id, this.createProxy(identifier));
    }
    return this._proxies.get(identifier.id);
  }

  private createProxy<T>(identifier: ProxyIdentifier<T>): T {
    return new Proxy({} as T, {
      get: (target, prop) => {
        return (...args: any[]) => {
          return this._rpc.invoke(identifier.id, prop as string, args);
        };
      }
    });
  }
}
```

```typescript
// 확장에서 명령 등록
class ExtHostCommands {
  registerCommand(id: string, callback: Function): IDisposable {
    this._commands.set(id, callback);

    // 메인 프로세스에 등록 알림
    this._mainThreadCommands.$registerCommand(id);

    return {
      dispose: () => {
        this._commands.delete(id);
        this._mainThreadCommands.$unregisterCommand(id);
      }
    };
  }

  // 메인 프로세스에서 호출됨
  $executeCommand<T>(id: string, ...args: any[]): Promise<T> {
    const command = this._commands.get(id);
    if (!command) {
      throw new Error(`Command not found: ${id}`);
    }
    return Promise.resolve(command(...args));
  }
}

// 메인 프로세스에서
class MainThreadCommands {

    CommandsRegistry.registerCommand(id, async (...args) => {
      // 확장 호스트로 전달
      return this._extHostCommands.$executeCommand(id, ...args);
    });
  }
}
```

## 6. 기여점 시스템

### 6.1 레지스트리 패턴

```typescript
interface IRegistry {
  add(id: string, data: any): void;
  knows(id: string): boolean;
  as<T>(id: string): T;
}

class RegistryImpl implements IRegistry {
  private readonly data = new Map<string, any>();

  add(id: string, data: any): void {
    if (this.data.has(id)) {
      throw new Error(`Contribution already exists: ${id}`);
    }
    this.data.set(id, data);
  }

  knows(id: string): boolean {
    return this.data.has(id);
  }

  as<T>(id: string): T {
    const data = this.data.get(id);
    if (!data) {
      throw new Error(`Unknown contribution: ${id}`);
    }
    return data as T;
  }
}

export const Registry: IRegistry = new RegistryImpl();
```

```typescript
class ContributionProcessor {
  processExtension(extension: IExtension): void {
    const contributes = extension.contributes;
    if (!contributes) return;

    // 명령 등록
    if (contributes.commands) {
      for (const cmd of contributes.commands) {
        this.registerCommand(cmd);
      }
    }

    // 메뉴 등록
    if (contributes.menus) {
      for (const [contextId, items] of Object.entries(contributes.menus)) {
        for (const item of items) {
          this.registerMenuItem(contextId, item);
        }
      }
    }

    // 설정 등록
    if (contributes.configuration) {
      this.registerConfiguration(contributes.configuration);
    }
  }
}
```

## 7. 확장 스캐너

### 7.1 스캔 프로세스

```typescript
class ExtensionScanner {
  async scanExtensions(locations: URI[]): Promise<IExtension[]> {
    const extensions: IExtension[] = [];

    for (const location of locations) {
      const found = await this.scanLocation(location);
      extensions.push(...found);
    }

    return this.validateAndSort(extensions);
  }

  private async scanLocation(location: URI): Promise<IExtension[]> {
    const entries = await this.fileService.readdir(location);
    const extensions: IExtension[] = [];

    for (const entry of entries) {
      if (entry.isDirectory) {
        const packageJson = URI.joinPath(location, entry.name, 'package.json');
        if (await this.fileService.exists(packageJson)) {
          const extension = await this.parseExtension(packageJson);
          if (extension) {
            extensions.push(extension);
          }
        }
      }
    }

    return extensions;
  }

  private async parseExtension(packageJsonUri: URI): Promise<IExtension | null> {
    try {
      const content = await this.fileService.readFile(packageJsonUri);
      const manifest = JSON.parse(content.toString());

      return this.validateManifest(manifest)
        ? this.createExtension(manifest, packageJsonUri)
        : null;
    } catch (error) {
      this.logService.warn(`Failed to parse extension: ${packageJsonUri}`, error);
      return null;
    }
  }

  private validateManifest(manifest: any): boolean {
    return !!(
      manifest.name &&
      manifest.version &&
      manifest.engines?.vscode
    );
  }
}
```

## 9. hdsp-agent 적용 가이드

### 9.1 플러그인 시스템 설계

```typescript
// 플러그인 인터페이스
interface IAgentPlugin {
  id: string;
  name: string;
  version: string;
  activate(context: PluginContext): Promise<void>;
  deactivate(): Promise<void>;
}

// 플러그인 컨텍스트
interface PluginContext {
  // 서비스 접근
  services: ServiceAccessor;

  // 기여점 등록
  registerTool(tool: IAgentTool): IDisposable;
  registerCommand(command: ICommand): IDisposable;
  registerProvider(provider: IProvider): IDisposable;

  // 이벤트 구독
  subscriptions: IDisposable[];
}
```

### 9.2 플러그인 매니저

```typescript
class PluginManager {
  private plugins = new Map<string, IAgentPlugin>();
  private activated = new Set<string>();

  async loadPlugin(path: string): Promise<void> {
    const manifest = await this.loadManifest(path);
    const module = await import(path);
    const plugin = module.default as IAgentPlugin;

    this.validatePlugin(plugin, manifest);
    this.plugins.set(plugin.id, plugin);
  }

  async activatePlugin(id: string): Promise<void> {
    const plugin = this.plugins.get(id);
    if (!plugin || this.activated.has(id)) return;

    const context = this.createContext(plugin);
    await plugin.activate(context);
    this.activated.add(id);
  }

  async deactivatePlugin(id: string): Promise<void> {
    const plugin = this.plugins.get(id);
    if (!plugin || !this.activated.has(id)) return;

    await plugin.deactivate();
    this.activated.delete(id);
  }
}
```
