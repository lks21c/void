# 도구 시스템

> **문서 목적**: Void의 도구 정의, 등록, 실행 패턴 분석 - hdsp-agent 코드 분석/생성 에이전트 개발 참고

---

## 1. 개요

Void의 도구 시스템은 LLM이 코드 편집, 파일 조작, 터미널 명령 실행 등의 작업을 수행할 수 있게 합니다. 15개 이상의 내장 도구와 MCP 프로토콜을 통한 외부 도구 통합을 지원합니다.

### 1.1 핵심 파일

| 파일 | 역할 | 크기 |
|------|------|------|
| `browser/toolsService.ts` | 도구 실행 서비스 | 24KB |
| `common/toolsServiceTypes.ts` | 도구 타입 정의 | - |
| `platform/mcp/common/mcpPlatformTypes.ts` | MCP 타입 | - |

### 4.3 도구 서비스 구현

```typescript
interface IToolsService {
  // 도구 등록
  registerTool(tool: IToolData): IDisposable;

  // 도구 조회
  getTool(id: string): IToolData | undefined;
  getAllTools(): IToolData[];

  // 도구 실행
  callTool(invocation: IToolInvocation): Promise<IToolResult>;

  // 이벤트
  onToolRegistered: Event<IToolData>;
  onToolExecuted: Event<{ invocation: IToolInvocation; result: IToolResult }>;
}

class ToolsService implements IToolsService {
  private readonly tools = new Map<string, IToolData>();

  registerTool(tool: IToolData): IDisposable {
    this.tools.set(tool.id, tool);
    this._onToolRegistered.fire(tool);

    return {
      dispose: () => this.tools.delete(tool.id)
    };
  }

  async callTool(invocation: IToolInvocation): Promise<IToolResult> {
    const tool = this.tools.get(invocation.toolId);
    if (!tool) {
      return {
        callId: invocation.callId,
        result: `Tool not found: ${invocation.toolId}`,
        isError: true
      };
    }

    try {
      const result = await this.executeInternal(tool, invocation);
      return { callId: invocation.callId, result };
    } catch (error) {
      return {
        callId: invocation.callId,
        result: error.message,
        isError: true
      };
    }
  }
}
```

### 5.4 MCP JSON-RPC 통신

```typescript
class McpServerRequestHandler {
  private _nextRequestId = 1;
  private readonly _pendingRequests = new Map<number, PendingRequest>();

  async sendRequest<T extends MCP.ClientRequest>(
    request: Pick<T, 'params' | 'method'>,
    token: CancellationToken = CancellationToken.None
  ): Promise<MCP.ServerResult<T>> {
    const id = this._nextRequestId++;

    return new Promise((resolve, reject) => {
      this._pendingRequests.set(id, { resolve, reject });

      this.send({
        jsonrpc: '2.0',
        id,
        method: request.method,
        params: request.params
      });

      // 취소 처리
      token.onCancellationRequested(() => {
        this._pendingRequests.delete(id);
        reject(new CancellationError());
      });
    });
  }
}
```

## 7. 코드 편집 도구 상세

### 7.1 Fast Apply 메커니즘

```typescript
class EditFileHandler {
  async apply(tool: EditFileTool): Promise<EditResult> {
    const document = await this.readDocument(tool.path);
    let content = document.getText();

    const changes: TextChange[] = [];

    for (const block of tool.searchReplaceBlocks) {
      const index = content.indexOf(block.search);
      if (index === -1) {
        throw new Error(`Search string not found: ${block.search.slice(0, 50)}...`);
      }

      changes.push({
        offset: index,
        length: block.search.length,
        text: block.replace
      });
    }

    // 역순으로 적용 (오프셋 유지)
    changes.sort((a, b) => b.offset - a.offset);

    for (const change of changes) {
      content =
        content.slice(0, change.offset) +
        change.text +
        content.slice(change.offset + change.length);
    }

    await this.writeDocument(tool.path, content);
    return { success: true, changesApplied: changes.length };
  }
}
```

### 7.2 Diff 마커 형식

LLM 응답에서 사용되는 Diff 형식:

```
<<<<<<< ORIGINAL
function oldFunction() {
  return 'old';
}
=======
function newFunction() {
  return 'new';
}
>>>>>>> UPDATED
```

파싱 로직:

```typescript
interface DiffBlock {
  original: string;
  updated: string;
  startLine: number;
  endLine: number;
}

function parseDiffBlocks(content: string): DiffBlock[] {
  const blocks: DiffBlock[] = [];
  const regex = /<<<<<<< ORIGINAL\n([\s\S]*?)\n=======\n([\s\S]*?)\n>>>>>>> UPDATED/g;

  let match;
  while ((match = regex.exec(content)) !== null) {
    blocks.push({
      original: match[1],
      updated: match[2],
      startLine: getLineNumber(content, match.index),
      endLine: getLineNumber(content, match.index + match[0].length)
    });
  }

  return blocks;
}
```

### 7.3 DiffZone 시스템

```typescript
interface DiffZone {
  id: string;
  uri: URI;
  originalRange: IRange;
  modifiedContent: string;
  status: DiffZoneStatus;
}

type DiffZoneStatus =
  | 'pending'      // 적용 대기
  | 'streaming'    // 스트리밍 중
  | 'applied'      // 적용 완료
  | 'cancelled';   // 취소됨

class DiffZoneManager {
  private zones = new Map<string, DiffZone>();

  createZone(uri: URI, range: IRange): DiffZone {
    const zone: DiffZone = {
      id: generateId(),
      uri,
      originalRange: range,
      modifiedContent: '',
      status: 'pending'
    };
    this.zones.set(zone.id, zone);
    return zone;
  }

  updateStreaming(zoneId: string, content: string): void {
    const zone = this.zones.get(zoneId);
    if (zone) {
      zone.modifiedContent = content;
      zone.status = 'streaming';
      this.renderDiff(zone);
    }
  }

  applyZone(zoneId: string): void {
    const zone = this.zones.get(zoneId);
    if (zone) {
      // 실제 파일에 변경 적용
      this.applyToDocument(zone);
      zone.status = 'applied';
    }
  }
}
```
