# Void 프로젝트 개요

> **문서 목적**: hdsp-agent 코드 분석/생성 에이전트 개발을 위한 Void 프로젝트 분석 참고 자료

---

## 1. 프로젝트 소개

### 1.1 Void란?

**Void**는 Microsoft VSCode를 포크하여 개발된 오픈소스 AI 코딩 어시스턴트입니다. Cursor IDE의 대안으로 개발되었으며, 다양한 LLM 프로바이더를 지원하는 것이 특징입니다.

| 항목 | 내용 |
|------|------|
| 프로젝트 유형 | AI 코딩 어시스턴트 (IDE) |
| 기반 | Microsoft VSCode (Electron) |
| 라이선스 | 오픈소스 |
| 주요 목표 | 멀티 LLM 프로바이더 지원, 오픈소스 Cursor 대안 |

### 1.2 핵심 기능

1. **멀티 LLM 프로바이더 지원**
   - 20개 이상의 LLM 프로바이더 지원
   - 로컬(Ollama, LM Studio) 및 클라우드(OpenAI, Anthropic) 모두 지원
   - 동적 모델 탐지

2. **코드 편집 시스템**
   - Fast Apply: 검색/치환 기반 빠른 적용
   - Slow Apply: 전체 파일 재작성
   - 실시간 Diff 시각화

3. **체크포인트 시스템**
   - 코드 변경 전 상태 자동 저장
   - 원클릭 롤백 지원

4. **MCP 프로토콜 지원**
   - Model Context Protocol 2024-11-05 지원
   - 외부 도구 통합
   - stdio 및 SSE 전송 방식

5. **도구 시스템**
   - 15개 이상의 내장 도구
   - 파일 읽기/쓰기, 검색, 터미널 명령 실행
   - 도구 승인 워크플로우

## 2. 기술 스택

### 2.1 핵심 기술

| 분류 | 기술 | 버전 |
|------|------|------|
| 기반 플랫폼 | Electron | VSCode 기반 |
| 주요 언어 | TypeScript | 5.8 (개발 버전) |
| UI 프레임워크 | React | 19.1.0 |
| 스타일링 | TailwindCSS | 3.4.17 |
| 빌드 도구 | Gulp, Webpack | - |

### 2.2 LLM SDK

```json
{
  "@anthropic-ai/sdk": "Claude API",
  "openai": "OpenAI API",
  "@mistralai/mistralai": "Mistral API",
  "groq-sdk": "Groq API",

```

### 2.3 프로토콜 및 통합

| 프로토콜 | 용도 |
|----------|------|
| MCP (Model Context Protocol) | 외부 도구 통합 |
| IPC (Inter-Process Communication) | 프로세스 간 통신 |
| JSON-RPC | MCP 서버 통신 |

### 2.4 UI 라이브러리

- **lucide-react**: 아이콘 시스템
- **react-tooltip**: 툴팁 컴포넌트
- **PostCSS**: CSS 전처리

## 4. 듀얼 프로세스 아키텍처

### 4.1 아키텍처 다이어그램

```
┌──────────────────────────────────────────────────────────────┐
│                    Browser Process (Renderer)                 │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐   │
│  │  React UI   │  │  Services   │  │  IPC Client         │   │
│  │  Components │  │  (Singleton)│  │  (Channel Proxy)    │   │
│  └─────────────┘  └─────────────┘  └──────────┬──────────┘   │
└───────────────────────────────────────────────┼──────────────┘
                                                │
                                    IPC 채널 (타입 안전 메시징)
                                                │
┌───────────────────────────────────────────────┼──────────────┐
│                    Electron Main Process                      │
│  ┌─────────────────────┐  ┌─────────────────────────────┐    │
│  │  LLM Provider       │  │  IPC Server                 │    │
│  │  Implementation     │  │  (Channel Handler)          │    │
│  │  ├─ OpenAI          │  └─────────────────────────────┘    │
│  │  ├─ Anthropic       │                                      │
│  │  ├─ Ollama          │  ┌─────────────────────────────┐    │
│  │  └─ ...             │  │  MCP Server Manager         │    │
│  └─────────────────────┘  └─────────────────────────────┘    │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐     │
│  │  Node.js 기능: 파일 시스템, 터미널, 네트워크        │     │
│  └─────────────────────────────────────────────────────┘     │
└───────────────────────────────────────────────────────────────┘
```

### 4.2 프로세스 역할

| 프로세스 | 역할 | 접근 가능 리소스 |
|----------|------|------------------|
| Browser (Renderer) | UI 렌더링, 사용자 인터랙션 | DOM, React, 서비스 싱글톤 |
| Electron Main | Node.js 작업, 외부 통신 | 파일 시스템, 네트워크, 터미널 |

## 5. 빌드 시스템

### 5.1 빌드 도구 체인

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│    Gulp     │ ──► │  TypeScript │ ──► │   Webpack   │
│ (Task Runner)     │  (Compiler) │     │  (Bundler)  │
└─────────────┘     └─────────────┘     └─────────────┘
                           │
                    ┌──────┴──────┐
                    │   ESLint    │
                    │  (Linting)  │
                    └─────────────┘
```

### 5.2 주요 빌드 태스크

| 태스크 | 설명 |
|--------|------|
| `compile` | TypeScript 컴파일 |
| `watch` | 파일 변경 감지 및 재컴파일 |
| `bundle` | Webpack 번들링 |
| `lint` | ESLint 검사 |
| `test` | 테스트 실행 |

### 5.3 React 컴포넌트 빌드

React 컴포넌트는 별도로 컴파일되어 `react/out/` 디렉토리에 출력됩니다:

```
void/browser/react/
├── src/               # React 소스
│   ├── sidebar-tsx/
│   └── ...
└── out/               # 컴파일된 출력
```
